# deepseek-store
DeepSeek Store is a responsive storefront demo for exploring AI service plans, API packages, development tools, and prompt resources. Built with HTML, CSS, and vanilla JavaScript, it includes a home page, an interactive product catalog, product details, and registration and contact forms.

Users can search products by name or description, filter them by category, sort by price, popularity, or name, and save favorites for comparison. The shopping cart supports quantity adjustments, item removal, and a simulated checkout flow with input validation, an itemized summary, and an order confirmation. Cart contents, favorites, and theme preferences are saved locally in the browser.

The interface includes light and dark themes, responsive layouts, and collapsible mobile navigation. The project demonstrates DOM manipulation, event handling, form validation, hash-based navigation, and localStorage without external JavaScript frameworks. Products and prices are illustrative; registration, contact submission, and checkout are demonstrations that do not create real accounts, send messages, or process payments.
