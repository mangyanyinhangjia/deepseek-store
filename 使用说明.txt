使用说明

1. 解压整个文件夹后，双击 index.html 可以浏览网站。
2. 推荐使用 VS Code 的 Live Server 打开整个项目，确保跨页面购物车、收藏保存一致。
3. 如果电脑已有 Node.js，在该文件夹终端运行 node server.cjs，然后打开 http://127.0.0.1:4173。
4. 四个页面：index.html 首页、catalog.html 产品目录、product.html 产品详情、contact.html 注册与联系。
5. data.js 是演示产品数据；app.js 是主要交互代码；style.css 是样式与响应式布局。
6. 产品和价格均为课程演示数据。表单不发送消息、不创建真实账户，购物车不处理付款。
7. 演示顺序：首页 → 目录搜索/分类/排序 → 产品详情 → 购物车/收藏 → 表单错误与成功提示 → 深浅主题 → 手机菜单。

已检查：产品展示、组合筛选、排序、无结果提示、详情页、无效产品、购物车添加/移除/刷新保存、收藏保存、注册验证、联系表单 Guest 默认值、主题保存、390px 手机导航与布局。浏览器检查使用本机 Edge。
